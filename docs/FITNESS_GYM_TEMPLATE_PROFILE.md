## Four distinct business models

| Template | Operator / customer | Business model | Visual identity |
|---|---|---|---|
| IRONFORGE Performance Club | Strength gyms, bodybuilding and powerlifting clubs | Facility discovery, coaching programmes, membership and induction enquiries | Industrial editorial, charcoal/bronze, condensed display type, hard-edged composition |
| PULSE Athletic Studio | Boutique HIIT, cycling and group-fitness studios | Class discovery, timetable information, passes and instructor-led requests | Kinetic, coral/navy, modular class blocks and energetic typography |
| BALANCE HOUSE | Yoga, Pilates and mindful-movement studios | Practice discovery, instructor information, workshops and class enquiries | Natural minimalism, sage/stone, soft editorial spacing and quiet composition |
| ATHLETE LAB | Sports-performance centres and personal coaches | Performance services, assessments, athlete development and team enquiries | Technical/data-led, blue/ink, precision grid and performance-report language |

## Page architecture and visual assets

- Each template has **40 meaningful page types**, including its own home, service/programme pages, coaches or instructors, schedules, membership/pass or assessment information, request flows, policies, contact and support content.
- Each website has **83 unique page-specific first-party SVG asset IDs**: five on the homepage and two on each of the other 39 pages.
- Assets are generated by the template-specific `fitnessArtSrc()` renderer using unique page/asset IDs, distinct palette tokens and fitness scene categories. They are not stock photographs or photographs of actual facilities, trainers or members.
- No third-party image hotlinks are used for the Fitness visual system. The page metadata stores asset ID, alt text, scene, purpose, source, creator, license, path and date checked.

## Customer journeys

- Discover a facility, practice, class or performance service.
- Review operator-maintained information about schedules, programmes, facilities, coaches and fees.
- Submit a membership, class, personal-coaching, team or assessment enquiry.
- Enquiries are saved through the existing shared quote-request workflow and are explicitly **not** represented as confirmed bookings, membership activation, assessments or payments.
- Live class availability, calendar booking, online payment and membership billing are not enabled by this template release. Operators must configure and verify these before offering them as live services.

## Engineering integration

- Reuses the existing WordPress Studio admin, Neon API, website/page document model and shared storefront runtime.
- Adds Fitness keys to the existing template allowlist and category mapping.
- Adds page-catalog generation fallback and release guards for exactly 40 pages and 83 unique image IDs.
- Adds four dedicated admin preview concepts, storefront page renderers, responsive design tokens and enquiry handling.
- Uses website-scoped page documents and the existing quote-request API; no second admin or booking engine is introduced.
- Migration `wordpress-app/migrations/20261109_fitness_gym_four_templates.sql` is additive and idempotent; no existing catalog, page, website or order rows are deleted.
